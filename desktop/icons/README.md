# Desktop Icons

这个目录用于存放 VNASeek 桌面版图标资源。

## 当前内容

1. `app-icon.svg`
   - 作为图标母版。
   - 当前为占位但可用的品牌方向稿。

## 建议输出文件

建议基于 `app-icon.svg` 生成以下文件，并放在本目录下：

1. `32x32.png`
2. `128x128.png`
3. `128x128@2x.png`
4. `icon.png`
5. `icon.ico`

如需额外导出给安装包、设计稿或宣传图，可继续保留这些尺寸：

1. `16x16.png`
2. `24x24.png`
3. `48x48.png`
4. `64x64.png`
5. `256x256.png`
6. `512x512.png`

## Tauri 生成方式

安装完桌面开发依赖后，在 `desktop/` 目录执行：

```bash
npm install
npm run tauri icon ./icons/app-icon.svg
```

`icon.ico` 需要至少包含以下图层：

1. `16x16`
2. `24x24`
3. `32x32`
4. `48x48`
5. `64x64`
6. `256x256`

## 设计约束

1. 小尺寸图标优先保留“播放三角形 + 下载箭头”主体。
2. 波形线条只作为辅助，不应在 `16x16` 或 `24x24` 中占主导。
3. 深色底板和亮色主形状必须保持高对比，保证任务栏与开始菜单可辨识。
